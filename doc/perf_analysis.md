# 性能分析方案 — RV32I 5 级流水线 vs 大三单周期（实验一定稿，T32–T35）

> 版本：v1.0（日期见变更记录）
> 状态：**方案定稿待执行**（任务 T32–T35 见 `doc/tasks.md` §4）
> 关联：`doc/top_design.md`（结构/冲突策略口径）、`doc/isa.md`（指令清单与 HALT 约定）、`doc/ref_note.md`（单周期对比基线 = `ref/CPU/`）、`doc/tasks.md` §1 行"量化性能测试"。
> 原则：**测量不改 RTL**；一切观测经 TB 层次引用；正确性回归绿是性能数据有效的前置门禁。

---

## 1. 目的与范围

1. 输出实验一报告要求的量化性能指标：**CPI / IPC / MIPS / CPU time / 加速比**，并**对比大三单周期 CPU**（`ref/CPU/`，RV32I 单周期，仅 clk/rst 顶层）。
2. 量化流水线停顿来源（load-use 冻结、分支/跳转冲刷），用**恒等式自检**保证测量可信。
3. 补充面积（LUT/FF）与 **Fmax**（post-synth timing）对比，支撑"流水线 vs 单周期"报告的完整结论。
4. 与实验二（UART SoC）解耦：本方案只测 CPU core（`pipeline_top`，`SOC_BUILD=0`）。

## 3. 指标定义（全以仿真实测为准）

记（计数见 §5.2）：
- `IC`：动态退休指令数——自首条真实指令退休至 **HALT 首次退休（含该条）** 计得；每拍至多 1 条退休。
- `F`：首条真实指令退休所在拍号（复位释放后第 1 个 clk 沿记拍 1）。头部气泡拍数 = `F−1`（流水线填充，正常 =4）。
- `C`：总拍数 = HALT 首次退休拍号（含填充与全部停顿）。
- `L`：load-use 冻结拍数（冻结使 ID/EX 灌 1 气泡 → 每冻结加 1 拍）。
- `T`：PC 重定向（flush）次数 = beq/bne taken + jal/jalr 恒跳；每次冲刷 2 条 → 加 2 拍。
- 无结构冒险（哈佛存储分离），无其他停顿源。

指标：

| 指标 | 公式 | 说明 |
|---|---|---|
| CPI | `C / IC` | 含填充的宏观 CPI（与单周期对比的主口径） |
| CPI_steady | `(C − (F−1)) / IC` | 剔除固定填充后的稳态 CPI（结构分析用） |
| IPC / IPC_steady | 倒数 | |
| 停顿占比 | `L/C`、`2T/C` | 停顿来源分解（§5.4） |
| MIPS | `IC / (C·Tclk) × 10⁻⁶` | 名义 100 MHz 下 |
| CPU time | `C × Tclk` | |
| 结构加速比 | `IC / C`（= 单周期拍数/流水线拍数） | 单周期 CPI≡1 → 单周期拍数 = IC |
| 时间加速比 | `(IC/C) × (f_pipe/f_single)` | 两设计时钟不同时才偏离结构加速比 |

**恒等式（测量自检，TB 断言）**：`C = IC + (F−1) + L + 2T`。成立 ⇒ 停顿记账完整、无漏计；不成立 ⇒ 测量无效，先修 TB。

## 5. 测量实现（全部在仿真侧，不改 RTL）

### 5.1 正确性前置
先跑整机回归（run_tb.ps1 全绿、tb_prog_* 逐项 PASS）→ 同一镜像/同一构建再跑性能 TB。**性能数据与正确性同源同镜像**。

### 5.2 性能 TB（`src/test/tb_perf.v`，新任务 T32）
- 例化 `pipeline_top u_cpu(...)`（SOC_BUILD=0）；`$readmemh("<prog>_rom.hex")` 灌 `u_cpu.u_imem.mem`（沿用 tb_prog_* 既有灌法与清零惯例）。
- 拍计数：`rst` 释放后每个 `posedge clk` 计数 `cyc`。
- 退休观测（层次引用，实例名以 pipeline_top 例化名为准，编码前先核对）：
  - 真实指令退休：WB 段 `inst ≠ 32'h0`（复位气泡）且 `≠ 32'h13`（flush NOP，见 if_id 文档口径）→ `ic++`；首个满足拍的编号记 `F`。
  - HALT：WB 段 `inst == 32'h0000_0063` → 锁存 `C = cyc`，停止计数。
  - `L`：`pc_freeze` 拉高拍计数（hazard 单元输出/顶层 wire）。
  - `T`：flush/PC 重定向事件计数（`br_taken` 或 jump 选通，等价 PC≠pc+4 的事件）。
- 程序选择用编译期开关：`\`ifdef PERF_SORT … \`endif` 5 档（脚本按档 xvlog `-d`），避免仿真期字符串参数化。
- 输出一行 CSV：`prog,IC,F,C,L,T,CPI,IPC,CPI_steady` + 恒等式 PASS/FAIL 断言（`C == IC+(F−1)+L+2T`）。
- 回归复用：同一 TB 同时把 regfile/dmem 终值与各程序注释期望比对（照抄 tb_prog_* 断言段），**防止"为快而错"**。

### 5.3 运行脚本（T33）
`src/scripts/run_perf.ps1`（仿 run_tb.ps1 框架）：逐档 xvlog+xelab+xsim → 解析各 log 的 CSV 行 → 汇总 `src/scripts/out/perf_summary.csv`（含恒等式结果列），打印 `== PERF ALL PASS ==`（要求：5 档恒等式全过且正确性断言全绿）。

### 5.4 停顿分解（分析用）
按程序输出表：`C = 理想拍(IC) + 填充(F−1) + load-use(L) + 冲刷(2T)`。报告据此画堆叠图与"CPI 超 1 的来源"表。

## 6. 单周期基线获取（T34）

1. 先取**理论基线**：单周期 CPI≡1 → `cycles_single = IC`（同镜像同 IC），结构加速比 = `IC/C`（§3），**无需仿真即可得主结论**；IC 用 §5.2 的 TB 计数（与设计无关）。
2. 复测项（时间允许时做，供引用"同条件实测"）：
   - 只读源**副本**置于 `build/ref_synth/`（`ref/CPU/` 本身零改动；`build/` 入 .gitignore）：复制 `ref/CPU` 的 rtl/defines → 新建综合工程（沿用 `synth_check.tcl` 家族脚本写法）→ post-synth timing 取 Fmax、资源数。
   - 单周期 Fmax 对比流水线 Fmax → 报告"时间加速比"行（两列时钟不同时用）。
   - 大三历史数据（原课程设计报告）仅作旁证引用，须注明出处；与复测不一致时以复测为准并备注差异原因。

## 10. 风险与开放项

| 项 | 说明/缓解 |
|---|---|
| WB 段"真实指令"判据的边界 | 以 `inst≠0/0x13` 判真实；需核对 5 个 asm 的 .lst 不含真 `0x13`/`0` 编码（build_asm 产物核对步骤），否则改用 WB 控制位组合判据 |
| 层次引用名漂移 | RTL 例化名变更会破坏 TB；编码前核对 pipeline_top 内部实例名，并在 tb_perf.v 头注释登记 |
| HALT 首次退休 vs 固定周期采样 | 与既有 tb_prog_*（固定周期采样）判据不同，属**独立新增** TB；两份回归并行保留 |
| ref 历史数据缺失/不可比 | 主结论不依赖历史数据（理论基线 = IC 即可）；复测数据缺失时明确写"以同频理论基线为准" |
| 仿真耗时 | sort/hazard 程序长运行：xsim 跑拍数上限保护（超时判 FAIL），汇总时记录 |
| 填充拍数 F−1 非 4 | 复位时序/气泡初始值若与假设不同，恒等式断言会暴露；以实测 F 记账，不硬编码 |
