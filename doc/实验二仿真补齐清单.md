## 二、逐项做法、验收与 **📸 截图要点**

### 1 · 8N1 帧格式与位时序（已有，直接引用）

- **复现命令**：
  ```powershell
  powershell -File UART/src/scripts/run_wave868.ps1
  powershell -File UART/src/scripts/extract_frame_vcd.ps1
  ```
- **实测结论**：位宽 868 拍 = 8680 ns = **8.68 µs**；帧长（1 起始 + 8 数据 + 1 停止）= **86.8 µs**；波特率误差 **0.0064%**；帧内跳变全部落在整数比特边界（+0/+2/+3/+4/+6/+7/+8/+9 位）。
- **📸 必须入镜**：
  1. 位级 ASCII 时序图（**起始位低 / 8 位数据 LSB 先 / 停止位高**）；
  2. **时间标注 8680 ns 与 86800 ns** 与误差 0.0064%；
  3. 帧内跳变相对时刻表（证明跳变在比特边界）；
  4. VCD 作为附件（可用 Vivado/xsim 打开复核）。

### 2 · RX 位中心采样与抗噪

- **做法**：注入端与 DUT 分频**故意不等**（DUT 868、注入 860 / 876，约 ±1.8%），并在起始位附近**注入一个短毛刺**；记录 `uart_rx_pin`、内部采样状态（`state/cnt` 等）、`valid`、`data`。
- **验收**：① 毛刺**不产生** `valid`；② 偏移 ±2% 内仍采样正确、读回字节一致；③ 偏移过大（如 ±30%）→ **判无效并丢弃、不产出错误数据**。
- **📸 必须入镜**：
  1. **两张波形**：一张"临界偏移仍正确"、一张"超限即丢弃"；
  2. **游标标出采样点相对位中心的位置**（体现"位中心采样"）；
  3. 标注注入位宽 vs DUT 分频（如 860 clk vs 868 clk）；
  4. 附"偏移量 × 结果（收对/丢弃）"小表。

### 3 · 全双工并发与 `TX_BUSY` 语义

- **做法**：扩 `tb_uart_ip_top.v`：① RX 帧接收进行中写 TX → `STAT=2'b11`（`TX_BUSY` 与 `RX_VALID` 同现），两路各自完成；② TX 移位期间写第二个字节 → 被丢弃（无第二帧）；③ 连续 `putc` 不丢字。
- **验收**：① 同现且两路数据各自正确（TX 帧=0x5A、RX 读回=0x3C）；② 忙写丢弃后**停止位后 12 bit 窗口内无第二帧**；③ 连发 N 字节全部正确。
- **📸 必须入镜**：
  1. `tx_busy` 与 `rx_valid` **同拍为高**的区段（标出 `STAT=2'b11`）；
  2. **写 TX 那一拍**与 `tx_busy`/`tx_pend` 的关系（高亮"该次写被丢弃"）；
  3. 连续两帧之间**无覆盖**（标注 `STAT.bit0 = tx_busy | tx_pend`，即"忙"含挂起待发）；
  4. 两路完成后的数据对照（TX=0x5A / RX=0x3C）。

### 4 · 统一编址 MMIO + UART 回显全链路

- **做法**：新 TB（如 `soc/test/tb_wave_soc.v`）用 `tb_soc_full.v` 的激励（发 'A' → 注入 0x42 → 回显），记录
  `u_soc.u_cpu.cs_mmio`、`reg_off`、`mmio_we`、`mmio_wdata`、`mmio_rdata`、`uart_tx_pin`、`uart_rx_pin` 与访存地址。
- **验收**：首帧 `0x41`、回显帧 `0x42`，与 `tb_soc_full` 断言一致。
- **📸 必须入镜**（一张图讲完全链路）：
  1. `cs_mmio=1` + `reg_off=01`（STAT）读轮询；
  2. `reg_off=00`（TX）+ `mmio_we=1` + `mmio_wdata[7:0]=0x41` 写发送；
  3. 紧接着 `uart_tx_pin` 出现**起始位（低）+ 8 位数据**；
  4. `uart_rx_pin` 注入 `0x42` 帧后 `mmio_rdata` 读到 `0x42`（`reg_off=10`）；
  5. 回显段再写 TX → `uart_tx_pin` 发出 `0x42`；
  6. 标注**窗口基址 `0x0000_4000`** 与 `lw`=读 / `sw`=写；游标标出"写 TX 那一拍"与"起始位落下"的先后。
